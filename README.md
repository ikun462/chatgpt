# Solar Sandbox · 第一阶段地月物理实验室

这是实际创建、编译并运行过的 Godot 4 + C++ GDExtension 项目，版本 0.1.0。只交付第一阶段，不把后续碰撞、碎片、潮汐等功能计为完成。

## 先运行 Windows 便携版

1. 完整解压 `SolarSandbox-Stage1-Windows-x64.zip` 到可写目录，例如 `D:\SolarSandbox`。不要在 ZIP 内直接双击。
2. 双击 `启动模拟器.bat`，或直接运行 `SolarSandbox.exe`。`SolarSandbox.pck` 和 `solar_physics.dll` 必须与 EXE 保持同一目录。
3. 默认 Vulkan Forward+；若驱动无法启动，更新 AMD 驱动，或运行 `兼容模式启动.bat` 使用 OpenGL。兼容模式没有 Bloom，物理计算完全相同。
4. 这是一份**未签名的开发版本**。Windows 原生运行尚未在此云端完成验证；无需安装 Godot 编辑器才能运行便携版。

要求：Windows 10/11 x64；推荐使用用户给定的第 12 代 i3、RX 5700 XT 8GB、16GB 内存。60 FPS 是目标，不是本版本的实测承诺。

## 已实现

- 双精度 SI 单位 N 体引力内核，地球和月球互相施加引力；固定步长 Velocity Verlet。
- NASA 4K 地球、4K 月球、夜间灯光、真实数据云图的动态漂移、海洋高光、自转和太阳方向光。
- 大气薄壳近似、HDR 3D／色调映射、Forward+ Bloom、三档画质／MSAA。
- 自由旋转、缩放和键盘平移；地球、月球、全系统视角。
- 地球和月球质量独立调至原始值的 0.1–10 倍，实时改变后续运动。
- 暂停／继续、×1 到 ×864000 的目标倍率、10／60／300 秒固定步长。
- 同一物理求解器生成的 30 天轨道预览，以及运行时实际轨迹。蓝色为预测，青色为实际；近景隐藏轨道线，远景显示。
- 真实尺寸和 ×4 视觉放大严格分离；物理半径、引力、接触保护不变。
- 中文界面、模拟时间、实际倍率、FPS、CPU 积分耗时、能量／角动量误差、动量残差。
- 接触前停止并提示；重置恢复初始条件；所有纹理和字体已随包提供，不需要运行时联网。

## 操作

| 操作 | 控制 |
| --- | --- |
| 旋转／缩放 | 按住鼠标右键拖动／滚轮 |
| 自由平移 | 右键按住时 WASD；Q/E 上下；Shift 加速 |
| 暂停／继续 | 空格或下方按钮 |
| 聚焦选中天体 | F；左侧地球／月球按钮 |
| 查看轨道 | 点击“查看完整地月系统”，勾选轨道显示 |
| 调质量 | 左侧两个质量滑块，立即生效；保留位置和速度 |
| 恢复初始条件 | “重置地月系统”按钮 |

质量编辑属于外部干预，会改变系统能量和动量；编辑后重新记录守恒误差基线。显示的速度属于初始地月质心所定义的惯性参考系，编辑质量后并不强制把新质心静止化。太阳是固定方向照明，不是第三个引力天体。

## 物理真实性与边界

轨道位置只由 C++ 积分器更新，GDScript 不使用旋转动画驱动公转。球体自转和云层漂移只是表面视觉效果。初始条件由 NASA 的质量、半径、平均半长轴、偏心率和轨道倾角构造在近地点的理想化椭圆，整体平移至地月质心系；**不是指定历元的 JPL 星历**。孤立二体模型的周期不应被当作包含太阳扰动的真实月球周期。

大气采用受光薄壳／Fresnel 外观近似，尚非多重散射；云层是静态气象数据贴图的视觉漂移，尚非天气模型。海洋掩码从地表颜色估计，太阳光强为显示参数；没有日月食阴影、辐射传输或光度学标定。月球按公开平均恒星自转周期旋转，没有实现物理潮汐锁定、天平动。

第一阶段只有两个天体，O(N²) 对称直接求和比 Barnes–Hut 更合适。物理步进与绘制回调分开，但**尚未启用独立物理线程**；物理预算默认每个 Godot 物理回调 3 ms，超预算丢弃待追赶的模拟时间并提示，固定步长不变。该预算是软限制，单步不能被抢占。轨道预测目前在主线程进行，滑块调整后延迟 0.3 秒合并刷新请求；两体耗时很小，但不可直接扩展到数千碎片。

尚未实现：完整太阳系、太阳引力、质量以外的状态编辑、碰撞响应、独立碎片、潮汐、保存加载、GPU 物理、大规模 LOD、多线程物理。没有把视觉粒子冒充物理碎片。本阶段接触检测只沿 Verlet 漂移线段检测并回退整步，不声称精确求解接触时刻。
