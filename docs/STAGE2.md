# 第二阶段 2A–2C 碰撞与碎片原型

基于 main 6c918af069408b4538b97772084ec444c4d9e385。开发分支 feature/stage2-solar-collisions。第一阶段资源、测试、入口和 deliverables 发布包保留。

## 已实现与操作

从原中文界面的“第二阶段碰撞实验室”进入。独立启动脚本也可直接进入增强场景。
三个预设分别为两颗小行星、小行星撞月球、月球撞地球。速度可调，点击应用重新初始化。默认速度分别为 1000、8000、25000 m/s。小行星双体默认约九秒发生撞击。可选择 100、500、1000 碎片，暂停、修改时间倍率，按 ID 选择和追踪碎片，查看碰撞记录、质量、半径、密度及独立对象计数。
“恢复标准太阳系”创建太阳、八大行星和月球，太阳真实参与引力。现阶段其他行星使用基础材质，地球、月球仍使用原素材。
原始地月实验室仍保留原接触停止行为及所有第一阶段操作。

## 模型与精度边界

- 单位 kg、m、s，全状态 double。太阳系 t=0 是合成实验起点，无对应真实历元。各行星用圆形共面轨道，初始相位为人为固定的 0.7 rad 间隔，速度由圆轨道公式构造，再整体移至静止质心参考系。月球使用地球相对圆轨道近似。这不是 NASA/JPL 指定历元星历。
- 质量、半径和距离为 NASA NSSDCA 各行星 Fact Sheet 的圆整参数。来源 https://nssdc.gsfc.nasa.gov/planetary/factsheet/ 及其各行星详细表。坐标 y 为轨道法线。原第一阶段地月近地点初始化保留。
- swept-contact 求解 Verlet 漂移直线段与接触球的首次交点，按该段比例估算接触时刻。并非真实受力曲线的精确根。发生事件的子步采用旧加速度推进速度，碰撞步不承诺二阶能量误差。无接触步仍为原 Velocity Verlet。
- 低速合并保存质量、质心速度和体积。高速阈值为相对速度超过两倍相互逃逸速度，为经验近似，尚无材料强度或冲击流体模型。
- 破碎产生确定性、等质量、反向成对的抛射状态，分配 20% 质心系撞击动能给径向抛射。大质量比保留主体，抛射质量为较小天体质量的两倍。每块碎片独立参与全部两两引力、接触检测和后续合并，不使用视觉粒子替代物理对象。
- 生成位置是扩张的非重叠球壳，存在瞬时空间重分布与势能改变。没有严格总能量守恒，没有声称 80% 剩余能量得到完整热力学追踪。
- 轨道角动量差额存入各物体 spin_angular_momentum，诊断计入自旋角动量。未按转动惯量约束旋转动能，也未驱动网格自转。因此角动量账目可检查，完整能量与自旋耦合仍待实现。
- 事件记录含入射 ID、时间、相对速度、撞击能量和碎片数。被吸收对象从活动数组移除，事件保留其 ID。新 ID 单场景内单调生成。碎片二次碰撞采用合并，暂不递归破碎。
- 接触后继续余下步进。每次碰撞开启的 step 使用快照支持异常回滚。4096 条事件上限会明确报错并暂停。整个系统最多约 2102 活动对象。与无关天体重叠的抛射方案回退为合并。
- 连续 vector 存储，但仍是单线程 O(N²) 全相互引力与碰撞检测。未实现空间分区、Barnes–Hut 或异步预测，1000 碎片只作实验选项。基准结果不是完整帧率。

## API 兼容

原 reset、set_mass、advance、get_bodies、predict_orbits 均保留。get_bodies 新增 fragment 字段。
新增 load_scenario(scenario, speed, fragments)、get_collision_events。set_fixed_step 最小值扩至 0.01 s。
核心 System 默认保留接触回退语义，enable_collisions(true) 开启响应，预设加载会自动开启。
碰撞后数组索引可能改变，增强场景按唯一 ID 注册节点。原场景沿用固定地月接口。
增强场景复用 main.gd 的世界构造、材质、相机与 UI 工具，通过 stage2.gd 扩展，并未另建引擎项目。

## 尚未完成

2D/2E 的 1–3 万 MultiMesh 小行星带、选择提升、空间分区、多线程、行星全套纹理、土星环、冲击闪光与尘埃、通用创建和位置/速度矢量编辑面板、碰撞开关及精度选择面板尚未实现。
当前太阳系为十天体引力原型，未完成完整太阳系可视化验收。大型碎片回落/捕获的长期统计尚未验证，2000 碎片未测。本次交付范围是可构建的 2A–2C 原型，不是第二阶段全部功能完成版。
